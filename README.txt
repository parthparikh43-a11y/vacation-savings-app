VACATION SAVINGS TRACKER — iPHONE SETUP

Files:
- index.html: the app
- manifest.webmanifest and sw.js: install/offline support

To install it as an iPhone home-screen app:
1. Host the contents of this folder at an HTTPS address (for example, a private GitHub Pages site or another static HTTPS host).
2. Open that HTTPS address in Safari on your iPhone.
3. Tap Share → Add to Home Screen → Add.
4. Open the new home-screen icon.

Privacy and storage:
- Daily entries and the goal are stored in this browser on this device using localStorage.
- No account or server database is used by this starter version.
- Use Download backup regularly and keep the JSON file somewhere safe.
- Export CSV opens a spreadsheet-compatible log.
- Clearing Safari website data or changing browser/device can remove local entries. Restore from a backup to move records.

The app starts with no invented savings, and the vacation target is optional.
